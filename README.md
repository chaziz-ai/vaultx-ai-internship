# VaultX AI Internship
    
This repository contains my work for the VaultX Cyber Tech AI/ML Engineering Internship (Summer 2026). Each week focuses on a different set of AI engineering skills, building toward real-world LLM-powered applications.

## Setup

1. Clone the repository:

git clone https://github.com/chaziz-ai/vaultx-ai-internship.git
cd vaultx-ai-internship

2. Create and activate a virtual environment:

python -m venv venv
venv\Scripts\Activate.ps1

3. Install dependencies:

pip install -r requirements.txt

4. Create a `.env` file in the root folder with your API key:

OPENAI_API_KEY=your_api_key_here

week-01/ contains all Week 1 files: api_wrapper.py (reusable API wrapper), summarizer.py (CLI summarizer tool), first_api_call.py, glossary.md, temperature_test.ipynb, and temperature-experiment.md.
